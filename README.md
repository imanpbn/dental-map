# دنتال مپ (Dental Map) - سامانه ملی شفافیت قطعات و دایرکتوری ایمپلنت دندان ایران

پلتفرم جامع شفافیت، اصالت قطعات، شناسنامه دیجیتال ۳۲ دندان (FDI) و دایرکتوری جراحان و مراکز درمانی ایمپلنتولوژی ایران بر پایه معماری دیتابیس رابطه‌ای ۴ دامنه‌ای.

---

## 🚀 ویژگی‌ها و قابلیت‌های پیاده‌سازی شده

1. **معماری پایگاه داده رابطه‌ای ۴ دامنه‌ای (`database/schema.sql`)**:
   - **دامنه ۱ (جغرافیا و تقسیمات کشوری):** `countries`, `provinces`, `cities`, `districts` (با منطقه‌بندی پهنه‌های شمال، غرب، شرق، مرکز و جنوب تهران).
   - **دامنه ۲ (سلسله‌مراتب کمپانی‌ها و برندها):** `manufacturers`, `implant_brands`, `implant_types` با پشتیبانی از JSONB برای ویژگی‌های فنی (`extra_specs`)، طول عمر تضمینی و تکنولوژی سطوح بیواکتیو (SLActive, MPS, SA, XPEED).
   - **دامنه ۳ (پزشکان و تخصص‌ها):** `specialties`, `doctors` با اعتبارسنجی کد نظام پزشکی، جنسیت، رده سنی مراجعین و تعهد به صدور پاسپورت اصالت.
   - **دامنه ۴ (مراکز درمانی یکپارچه و بیمه‌ها):** جدول واحد `clinics` برای تفکیک مطب‌های شخصی، کلینیک‌ها و بیمارستان‌های شبانه‌روزی ۲۴/۷ و جدول واسط `clinic_insurances` برای پوشش بیمه‌های تکمیلی (دانا، ایران، البرز، سامان و تأمین اجتماعی).
   - **جداول واسط (Junction Tables):** `clinic_doctors` (با برنامه زمانی حضور شیفت‌ها) و `doctor_implant_types` (تطبیق جراح با برند ایمپلنت).

2. **کاتالوگ قطعات ۸ گانه استاندارد**:
   - `fixture` (فیکسچر حیاتی داخل استخوان)
   - `abutment` (اباتمنت پروتزی بافت نرم)
   - `healing` (شکل‌دهنده لثه)
   - `impression_coping` (انتقال موقعیت به لابراتوار)
   - `analog` (شبیه‌ساز فیکسچر در کست)
   - `surgical_kit` (کیت دریل، درایور و ترکمتر)
   - `scan_body` (شاخص اسکن دیجیتال برای Exocad و 3Shape)
   - `digital_analog` (آنالوگ پرینت سه‌بعدی)

3. **شبیه‌ساز شناسنامه هوشمند فک ۳۲ دندان (FDI 32-Tooth Digital Passport)**:
   - نمایش تعاملی دندان‌های ۱۱ تا ۴۸ در ۴ ربع فک بالا و پایین.
   - ثبت کد رفرنس (REF)، شماره لات (LOT)، برند، تورک سفت‌کردن اباتمنت (Ncm)، نام جراح و کلینیک.
   - امکان دانلود و چاپ نسخه رسمی با فرمت PDF به همراه بارکد QR استعلام بین‌المللی.

4. **موتور ارزش‌گذاری لیدهای پزشکی (Lead Valuation Engine)**:
   - فرمول ارزش‌گذاری اقتصادی: `newValuation = leads * 350,000 Toman`.
   - ثبت تعاملی تماس‌ها و نوبت‌های بیماران و گزارش تفکیکی در پنل مدیریت.

5. **مترجم بیومکانیک تراکم استخوان (D1 تا D4)**:
   - محاسبه خودکار تورک درج (Insertion Torque)، زاویه اباتمنت، پروتکل دریلینگ و تخمین عدد پایداری اولیه ISQ بر اساس طبقه‌بندی لک‌هولم و زارب.

6. **راهنمای تخصصی برند ناکسیس آلمان (Naxis Germany)**:
   - تحلیل اتصال دوگانه Dual Connection (هگز ۲.۱ + مورس تیپر ۱۱ درجه)، متالورژی تیتانیوم گرید ۴ سردکاری‌شده و سازگاری با سیستم استرا آکوا.

7. **دستیار شناساگر کد رفرنس (RefChatbot)**:
   - ویجت هوشمند شناوری جهت پاسخگویی به استعلام کدهای رفرنس و سازگاری قطعات.

## 🛠️ راهنمای اجرا

### پیش‌نیازها
- Node.js (نسخه ۱۸ به بالا)
- npm

### دستورات راه‌اندازی:
```bash
# نصب پکیج‌ها (در صورت نیاز مجدد)
npm install

# اجرای سرور توسعه (پورت 3000)
npm run dev

# یا اجرای سرور Express یکپارچه
npm run server

# بیلد پروژه برای محیط پروداکشن
npm run build
```

آدرس دسترسی محلی: [http://localhost:3000](http://localhost:3000)
